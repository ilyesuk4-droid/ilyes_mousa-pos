# نظام إدارة متجر الهواتف — Mobile Shop Manager

نظام نقطة بيع وإدارة مخزون محلي (بدون اتصال بالإنترنت) لمتاجر الهواتف والإكسسوارات.

## المميزات

1. **المنتجات**: إضافة/تعديل/حذف، بحث، فلترة حسب الفئة، تنبيه المخزون المنخفض، استيراد من CSV/Excel.
2. **الفئات**: إدارة فئات المنتجات.
3. **نقطة البيع (POS)**: قارئ باركود، سلة مشتريات، خصم، دفع كامل/جزئي/آجل.
4. **الفواتير**: طباعة فاتورة على ورق حراري 58 أو 80 مم.
5. **العملاء والكريدي**: سجل الديون، المدفوعات، كشف الحساب.
6. **المشتريات**: تسجيل البضاعة الواردة مع تحديث المخزون.
7. **حركات المخزون**: سجل كل عملية بيع وشراء وتعديل.
8. **لوحة التحكم**: إحصائيات اليوم، أفضل المبيعات، المخزون المنخفض.
9. **التقارير**: مبيعات وأرباح ومصاريف حسب فترة زمنية.
10. **المصاريف**: تتبع النفقات اليومية.
11. **ملصقات الباركود**: طباعة ملصقات Code128.
12. **الإعدادات**: اسم المتجر، الشعار، الهاتف، العنوان، فاتر الإيصال.
13. **النسخ الاحتياطي**: تصدير/استيراد كامل البيانات JSON.
14. **الإصلاحات**: إدارة طلبات الإصلاح مع تتبع الحالة والتكلفة.

## التقنيات

- **React 19** + **TanStack Start** + **TanStack Router**
- **Dexie.js** (IndexedDB) — جميع البيانات محلية بالكامل بدون خادم
- **Tailwind CSS v4** + **Radix UI**
- **TypeScript**
- دعم كامل لـ RTL، واجهة عربية وفرنسية، عملة دينار جزائري (دج)

## تشغيل المشروع محلياً

يحتاج Node.js ≥ 18 أو Bun.

```sh
# باستخدام bun (موصى به)
bun install
bun run dev

# أو باستخدام npm
npm install
npm run dev
```

ثم افتح المتصفح على `http://localhost:3000`

## البناء للإنتاج

```sh
bun run build
# أو
npm run build
```
